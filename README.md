# Zenith

Zenith is a personal workspace dashboard with a Windows desktop app.

## Download the Windows desktop app

Get the portable app from the Zenith website's **Download** page:

1. Choose **Instant download** to download the Windows ZIP.
2. Right-click the ZIP and choose **Extract All**.
3. Open the extracted folder and run **Zenith.exe**.
4. On its first launch, Zenith creates shortcuts on your Desktop and in the Start menu.

Keep the extracted app folder in place so those shortcuts continue to work. This is the packaged app; you do not need to install Node.js or build it from source.

## Website source

The dashboard source files are in the repository root. To use or host the website, download the repository files and serve the project with any static web server.
